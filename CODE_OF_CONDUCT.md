# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful. Disagree with ideas, not people.
- Assume good intent; ask before escalating.
- No harassment, slurs, or personal attacks. No politics in technical
  discussions unless directly relevant.
- Maintainers may remove comments, commits, or contributions that violate
  this code, and may temporarily or permanently ban contributors for
  patterns of bad behavior.

Reports go to the same private channel as security issues — see
[SECURITY.md](SECURITY.md).
